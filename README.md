# 학점 설계 웹 도구

별도 서버나 유료 API 없이 동작하는 한국어 학점 계산기입니다. 입력한 과목 정보는 사용자의 브라우저 로컬 저장소에만 보관합니다.

## 무료 공개 방법

1. GitHub 계정을 만들고 새 **Public repository**를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**에서 배포 소스로 `Deploy from a branch`를 선택하고 `main` / `/(root)`를 지정합니다.
4. 제공된 `github.io` 주소가 생성되면 휴대전화에서도 열리는지 확인합니다.

정적 페이지라 서버, 도메인, AI API 결제 없이 공개할 수 있습니다. 공개 저장소는 누구나 코드를 볼 수 있으므로 비밀번호나 API 키를 절대 추가하지 마세요.

## 수익화 순서

1. 먼저 학교별 평점 규정 안내, 사용 예시 등 직접 작성한 유용한 설명을 보강합니다.
2. 대학생 커뮤니티의 홍보 규칙을 확인한 뒤 도구를 소개하고 실제 사용 의견을 받습니다. 자동 게시나 가짜 방문·클릭은 하지 않습니다.
3. 사용자가 생긴 뒤 관련 제휴 링크를 검토합니다. 제휴 링크는 광고·수수료 관계를 분명하게 표시합니다.
4. 광고는 독창적이고 충분한 콘텐츠가 준비된 뒤 신청합니다. 승인과 수익은 보장되지 않으며, 방문자 확보가 먼저입니다.

이 파일은 배포 가능한 첫 시제품입니다. 공개 주소로 올리는 계정 작업과 이용자 모집은 계정 주인이 직접 해야 합니다. 지금 단계에서 실제 수입이 발생한다고 보장할 수는 없습니다.
