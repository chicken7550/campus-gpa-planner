# 캠퍼스 툴킷

대학생이 학점과 생활 계획을 한곳에서 정리할 수 있는 무료 정적 웹 도구입니다. 별도 서버나 유료 API 없이 동작하며, 입력 내용은 사용자의 브라우저에만 저장됩니다.

**공개 페이지:** https://chicken7550.github.io/campus-gpa-planner/  
**AI 업무 프롬프트 도구:** https://chicken7550.github.io/campus-gpa-planner/workflows.html

## 들어 있는 도구

- 학기 평점 및 누적 평점 목표 계산
- 과목 예시를 빠르게 채우는 시작 버튼
- 주거·식비·교통·학업·통신 등 월간 생활비와 잔액 계산
- 시급·주간 근무시간 기준 세전 알바 급여 예상
- 시험·과제 마감일 D-day 일정표
- 장학금 신청 준비 체크리스트
- 세션 목표 입력, 15·25·50분 집중 타이머, 오늘 완료 횟수와 7일 기록
- 주간 목표·실행·장애물·다음 행동 자기 점검
- AI 업무 프롬프트 생성, 복사·Markdown 다운로드, 즐겨찾기 저장
- 인쇄 및 PDF 저장, 페이지 주소 복사

`workflows.html`에서 학습 계획, 고객 문의, 상품 소개, SNS 게시물용 프롬프트를 입력값에 맞춰 만들 수 있습니다. AI API를 호출하지 않으며, 즐겨찾기는 브라우저에만 저장됩니다.

## 무료 배포

1. GitHub 저장소의 최상위에 `index.html`, `workflows.html`, `README.md`를 올립니다.
2. **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. 생성된 `github.io` 주소를 열어 페이지가 배포됐는지 확인합니다.

정적 페이지라 서버와 도메인 비용은 없습니다. 저장소 공개 시 코드는 누구나 볼 수 있으므로 비밀번호나 API 키를 넣지 마세요.

## 현재 수익 기능

이 페이지에는 결제, 광고, 제휴 링크가 연결돼 있지 않습니다. 따라서 방문자가 페이지를 이용해도 현재 자동으로 수익이 발생하지 않습니다. GitHub Sponsors 승인을 기다리는 중이라면 승인 후 후원 버튼을 연결할 수 있지만, 승인과 방문자 확보 및 후원은 별도이며 수익을 보장하지 않습니다.

입력은 현재 브라우저의 로컬 저장소에만 남고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 저장한 일정과 계산 정보도 사라질 수 있습니다. 알바 급여는 단순 세전 추정이며 주휴수당, 세금, 공제 등을 반영하지 않습니다.

## 인터페이스 원칙

첫 화면의 도구 바로가기, 예시 입력, 결과 요약, 집중할 일 입력, 최근 기록을 빠르게 보는 구성을 적용했습니다. [Pearson GPA 계산기](https://www.pearson.com/channels/calculators/gpa-calculator)의 빠른 시작 예시와 [Pomo 타이머](https://pomotimer.com/)의 세션 의도·진행 기록·기기 내 저장 패턴을 참고했습니다. 문구와 구현은 이 툴킷에 맞춰 작성했으며, 계산 기준은 학교별 차이가 있을 수 있으므로 안내를 함께 둡니다.

## 개선 점검 순서

방문자 수와 후원 전환을 확인할 수 있는 데이터 수집은 아직 연결돼 있지 않습니다. 따라서 실제 성과를 추측하지 말고, 매주 GitHub Pages 배포 상태·사용자 의견·승인 상태를 확인해 개선을 결정하세요. 후원 설정이 승인되기 전에는 작동하지 않는 결제 버튼을 넣지 않습니다.
